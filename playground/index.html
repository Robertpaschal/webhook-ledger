Sign and check a webhook

Produce the signature header a provider would send for a body, then check it with the same rules the library uses. Change one character of the body, the secret or the timestamp and check again to see why the raw bytes matter. Everything runs in this page with Web Crypto; nothing is sent anywhere. Use test secrets only.

Press Sign body, then Check header.



On a server, use the library instead of this page: it reads the raw request body, compares in constant time, and records the event once in Postgres. See the docs.
